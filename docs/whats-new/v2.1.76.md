# HopStat v2.1.76

Query results now have their own address — send someone the link, or copy the output straight into a ticket.

## What's New

- **Shareable query links** — every query writes a clean path to the address bar (`/ping/8.8.8.8`, `/bgp/1.1.1.0/24`, `/traceroute/1.1.1.1`). Opening that link re-runs the query, so a result can be handed to a peer or pasted into a ticket. When the query ran on a node other than the default one, the link keeps it as `?node=<id>`.
- **Copy link and Copy result** — the result panel has two new buttons. **Copy link** puts the shareable URL on the clipboard; **Copy result** copies a plain-text report with the command, target, node, output and the link. BGP lookups copy as parsed routes — prefix, next hop, AS path, communities — instead of raw terminal text.

## Notes

- **Admin password recovery is documented** — the README and the docs site now describe how to reset a lost admin password with `LG_FORCE_ADMIN_PASSWORD=1` and `--bootstrap`, for both systemd and Docker installs. The flow itself is unchanged; it was simply never written down.
