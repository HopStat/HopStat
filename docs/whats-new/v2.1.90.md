# HopStat v2.1.90

Hovering a hop lights only the specific path it lies on.

## Fixes

- **A hovered fallback hop lit its sibling fallbacks too** — when a node held more than one fallback, pointing at a hop on one of them highlighted the others as well, because the highlight only told live from backup, not one path from another. Every box and line on the map now knows the individual paths crossing it, so a hovered hop traces exactly the chains it is part of — nothing beside them. Hovering the node box still shows everything the node holds, and a hop shared by a live route and a fallback still prefers the live one.
