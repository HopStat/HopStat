# HopStat v2.1.75

BGP AS path map follows the learned route; GeoIP is used only when no route exists.

## Fixes

- **AS path map** — when a BGP route is present, the map and enriched AS list use only the route AS path; GeoIP `target_as` is no longer appended (fixes extra AS hops such as AS6939 on prefixes where the route ends at a different origin).
- **GeoIP fallback** — when no BGP route is found, the map still falls back to GeoIP origin ASN for a single-hop display.

## Improvements

- **Update badge labels** — shorter “update available” text in EN/FR/DE/TR/RU so the admin version card badge no longer overflows on narrow layouts.
