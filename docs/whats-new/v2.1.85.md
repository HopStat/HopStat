# HopStat v2.1.85

A raw path lookup for the admin panel, for when a result disagrees with the router.

## What's New

- **Path lookup on Admin → BGP Neighbors** — enter a prefix, optionally pick a node, and see every path behind it exactly as it arrived. No best-path selection, no local AS prepended, no default-route synthesis: the flag shown is whatever the speaker reported, so what HopStat displays can be checked against what the neighbour actually advertised.
- Each path lists its **ADD-PATH identifier** — the one per-path signal a normal result discards — alongside the neighbour, node, next hop, AS path, origin, local preference, MED, age, and the **complete attribute set**, including attributes no other view reads (originator id, cluster list, aggregator and the rest).

## Notes

- The lookup reads the local routing table only; it does not query the router.
- Available to signed-in administrators, and only when BGP is configured.
