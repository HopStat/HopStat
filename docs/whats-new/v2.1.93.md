# HopStat v2.1.93

The coverage gate now means what it says.

## Improvements

- **Coverage is measured in statements, not in a rounded percentage** — the gate compared the figure `go tool cover` prints, which rounds, so a few uncovered statements in a tree this size still read as "100.0%" and passed. It now counts statements and names every block that is missing, so a gap fails the build instead of disappearing into the rounding. The two statements that had slipped through are covered: both are guards for a BGP lookup that returns nothing, which is what an LG node with no route to report produces.
