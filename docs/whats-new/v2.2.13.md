# HopStat v2.2.13

A shared query link runs once the page is ready, instead of failing the Turnstile check.

## Fixes

- **Shared links with Turnstile** — opening a query link directly no longer shows a security check error. The query waits until the page knows Turnstile is on and the check has passed, then runs on its own.

## Notes

- Node agent calls still use the node key and are not checked.
