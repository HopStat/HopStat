# HopStat v2.2.2

MaxMind credentials move into the admin panel, and the installer stops leaving nodes without the tools they need.

## GeoIP settings in the admin panel

- **MaxMind account, licence key and update interval are now editable under Admin → Settings.** They previously existed only in `config.yaml`, which meant a restart and shell access to change them. Existing config-file values still seed the settings on first run, so nothing has to be moved by hand.
- **Credentials take effect without a restart.** The updater used to decide at startup whether it had anything to do, so credentials entered later sat unused until the process was restarted. It now checks on every cycle.
- **The licence key never comes back out.** The panel is told only whether one is stored; the key itself is not returned by any endpoint, including the admin settings response, which previously included it in full.
- **Clearing the credentials sticks.** Removing them in the panel used to be undone at the next restart, because a value seeded from `config.yaml` could not be told apart from one that had never been set.
- Interval and account are checked before they are stored: an interval has to parse and be at least an hour — anything shorter only re-downloads files MaxMind publishes twice a week — and an account id has to be numeric. A licence key without an account, or the reverse, is refused rather than silently downloading nothing.

## Installer

- **`install.sh` now checks for `ping` and `traceroute` and installs them if they are missing.** A standalone or agent node runs both directly, and on a minimal image neither is present — so every ping and traceroute query failed at runtime with an exec error the operator had to go and find in the logs. Handles apt-get, dnf, yum, apk, pacman and zypper; when none is available, or the install fails, it says exactly what to install rather than stopping the installation.
