# HopStat v2.2.9

Turnstile can be turned on from the admin settings page.

## What's New

- **Turnstile settings** — Admin → Settings now has site key, secret, and hostnames for the public query check. Leave the secret blank to keep the one already stored. Turn off Turnstile disables the check and stops `config.yaml` from turning it back on at the next start.
- **Existing config** — values already set in `config.yaml` are copied into the panel on first start.

## Notes

- Hostnames are one public site name per line, for example `lg.example.net`. Do not list `localhost` on a production server.
- The node agent API still uses the node key and is not checked.
