# HopStat v2.2.10

Turnstile and MaxMind are managed from Admin settings, and the query form waits until the Turnstile widget is ready.

## What's New

- **Turnstile** — site key, secret, and hostnames are saved in the settings database from Admin → Settings. `config.yaml` no longer controls them.
- **MaxMind** — account ID, licence key, and update interval are saved in the settings database from Admin → Settings. `config.yaml` no longer controls them.
- **GeoIP files** — a new config only sets `geoip.db_dir`. The default directory is `/var/lib/hopstat/geoip`.

## Fixes

- **Turnstile widget** — the public query form waits until Cloudflare's script is ready before mounting, so the check appears on the form.

## Notes

- Values already stored in the settings database keep working after the upgrade.
- An existing `config.yaml` is not rewritten. Remove leftover `turnstile` and MaxMind account fields; only `geoip.db_dir` is read. If `db_dir` is missing, HopStat uses `/var/lib/hopstat/geoip`.
- The node agent API still uses the node key and is not checked.
