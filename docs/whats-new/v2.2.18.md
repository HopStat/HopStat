# HopStat v2.2.18

A design refresh across the query page and the admin panel. Your brand colour and palette are unchanged; the layout is calmer, with the query bar as the centre of the page.

## What's New

- **One query bar** — on desktop, node, command, target and the Query button are now a single bar with thin dividers, so a query reads left to right as one line. The whole bar lights up on focus, and the part you are on is tinted when you move with the keyboard.
- **Quick starts as runnable rows** — the quick-start cards are now rows in one list. The target sits on the right in large monospace, and a run icon appears on the row under the pointer. Recent queries show as small one-tap chips.
- **Result headline** — the line above a result shows the command as a tag, the target in large monospace and the node with a server icon, instead of `BGP · 1.1.1.1 · BURSA`.
- **Ping readouts** — values are larger and left-aligned, with small sentence-case labels.
- **Open the query page from admin** — a "Open looking glass" link in the admin top bar opens the public page in a new tab, so you can check a change right after saving.
- **Version and sign-out chips** — the bottom of the admin sidebar shows the HopStat version chip, styled like the one in the public footer, with Logout beside it.

## Changes

- Labels across the site — table headers, form labels, badges, stat cards — are in sentence case instead of all capitals.
- The "HopStat Admin" label above every admin page title was removed; the sidebar already says it.
- The flat brand tint replaces the gradient in the header band, and the decorative grid and glow behind the query page and admin pages were removed.
- The home page heading is larger and its description wraps on narrow screens instead of being cut off.
- The small "Home" link at the bottom of the admin sidebar was replaced by the top-bar link.

## Fixes

- **Doubled table corners** — admin and result tables drew a second rounded border inside their panel, so the corners showed two overlapping lines. Tables now have a single border.
