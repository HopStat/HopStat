# HopStat v2.1.78

BGP results now answer the question a looking glass exists for: does the path change depending on where you look from?

## What's New

- **Network map** — below the BGP routes table, a new diagram shows how *every* node with an established BGP session reaches the same target. Node boxes sit on the left, the origin AS on the right, and hops that several nodes share converge into a single box, so divergence is visible at a glance.
- **Traceable paths** — the queried node's route is highlighted in its own colour by default. Hovering (or tabbing to) another node moves the highlight, tracing that node's path end to end, including the hops it shares with others. Hovering an AS shows its organisation and country.
- **Nodes with no route are named** — a node that sees nothing for the target is listed under the map rather than silently dropped; "this node cannot reach it" is part of the comparison. Nodes reaching the target only through a default route are drawn with a dashed connector.
- **Copy result includes the comparison** — the plain-text report now carries a `nodes:` section with each node's prefix and AS path.

## Notes

- The map appears only when at least two nodes hold an established BGP session; with one node it would just repeat the AS path map above it.
- Data comes from the shared in-process routing table, so the extra views cost no network round trips and no extra query time. Remote agent nodes without BGP neighbors are not polled.
- The map streams in with the rest of the BGP result rather than arriving at the end.
