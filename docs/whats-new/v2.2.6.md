# HopStat v2.2.6

Homepage query bar polish and a release pipeline fix.

## Improvements

- **Query bar layout** — BGP/Ping/Traceroute command picker corners, top edge, and background now align with the target field; no extra vertical line after changing command.
- **Submit button label** — disabled Query/Sorgula text stays readable in light and dark themes (no washed-out label from whole-button opacity).
- **Site description** — subtitle no longer clips letter descenders (g, p, y) under the header.
- **Language selector** — open dropdown matches the header toolbar colours instead of the browser’s native menu styling.

## Fixes

- **Release build coverage** — migration v20 (`passive_mode` on BGP neighbors) is fully covered in tests so tagged releases pass CI again.
