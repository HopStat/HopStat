# HopStat v2.2.17

Self-update works again. v2.2.15 started refusing every redirect to another host, and GitHub delivers release files through exactly such a redirect.

## Fixes

- **Self-update could not download** — GitHub answers a release download with a redirect to its asset CDN (`release-assets.githubusercontent.com`). The redirect guard added in v2.2.15 refused that hop, so neither the binary nor `checksums.txt` could be fetched and the update stopped.
- **GeoIP downloads hit the same guard** — MaxMind hands its downloads to its own Cloudflare R2 host, which the guard refused as well.

Both now accept the vendor's documented download host, over HTTPS on the standard port only. Every other cross-host redirect is still refused.

## Notes

- **Updating from v2.2.15 or v2.2.16 needs one manual step.** Those versions refuse the redirect themselves, so the update button cannot reach this release. Run the installer once on the server; it upgrades in place and keeps your settings:

  ```
  curl -sSL https://raw.githubusercontent.com/HopStat/HopStat/main/install.sh | sudo bash
  ```

  Later updates work from the admin panel again.
