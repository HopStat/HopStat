# HopStat v2.1.87

The network map reads correctly when one node holds a fallback the others do not.

## Fixes

- **A fallback hop was drawn as though it were live** — a hop belonging only to another node's backup path was drawn solid, because whether a path counted as a fallback was judged solely against the node in focus. A hop no node routes over live is now drawn dashed whoever is in focus, so an alternate upstream is no longer mistaken for part of the current path.
- **A live route appeared to pass through an unrelated hop** — an edge spanning more than one column ran straight under whatever box sat between, reading as though the path went via that hop. Such an edge is now bowed clear, and only when a box actually stands in its way.

## Improvements

- **Hops sit level with the nodes that use them** — instead of stacking from the top of each column, a hop settles on the average row of the nodes crossing it. One every node reaches lands centred on the fan; one only a single node reaches drops beside it, into space that was empty before.
- **Room between the nodes and the first hop**, so the fan has space to open.
