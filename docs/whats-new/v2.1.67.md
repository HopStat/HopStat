# HopStat v2.1.67

Admin What's New flow, aggregated release notes, and more reliable update status when GitHub is rate-limited.

## What's New

- **What's New modal** — scrollable release notes with per-version sections (`v2.1.64` → `v2.1.67`), version path chips under the title, and a **Update** button when a self-update is available (reloads the page after upgrade without reopening the modal).
- **Version dashboard card** — redesigned layout with status badge and `current → target` chips; click the card to open What's New.
- **Aggregated changelog** — `/admin/update/status?since=` returns combined notes for every version between last seen and latest.
- **Embedded release notes fallback** — when the GitHub API is unavailable, update status uses bundled `docs/whats-new` files so admins still see changelog content.
- **Update status cache** — short TTL cache reduces repeated GitHub calls and HTTP 429 errors on the admin dashboard.

## Fixes

- **BGP prefix column** — full IPv4/IPv6 CIDR values display without clipping in the route table.
- **Version card errors** — failed status checks show the real API message with a Retry action instead of a misleading “not configured” label.
