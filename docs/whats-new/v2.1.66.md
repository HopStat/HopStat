# HopStat v2.1.66

Fix BGP host lookups that resolve via the default route showing incomplete or inconsistent prefixes.

## Fixes

- **Host IP via default route** — when a host query (e.g. `213.146.165.165`) has no specific route and matches `0.0.0.0/0`, the table now shows the full queried prefix (`/32`) with the **Via default route** badge instead of a clipped or mismatched prefix.
- **Prefix column width** — widen the BGP route table Prefix column so full IPv4 `/32` values are not cut off (e.g. `213.146.165.165/32` no longer appears as `213.146.165.165/`).
- **Malformed prefix normalization** — backend normalizes incomplete prefix strings (trailing slash without mask) before display.
