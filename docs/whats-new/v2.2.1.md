# HopStat v2.2.1

The frontend's logic layer is now measured, so its test coverage cannot quietly slide.

## Under the hood

- **A coverage floor for the frontend logic layer.** Everything under `src/lib` and `src/hooks` is now measured — including files no test imports, which previously did not appear in the report at all — and the build fails if coverage drops below the current level. It is a ratchet rather than a target: set just under today's measurement so it catches a regression without demanding low-value tests to reach a round number. Components and pages are deliberately outside it; they are covered by the browser suite, which exercises them as rendered pages instead.
