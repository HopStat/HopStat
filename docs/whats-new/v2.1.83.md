# HopStat v2.1.83

Jump between nodes straight from the map, and see at a glance which route is live.

## What's New

- **Click a node to query it** — clicking a node on the network map re-runs the same lookup from that node. The result, the node selector, the highlighted route and the shareable link all follow, so comparing two vantage points is one click instead of a new query. Keyboard works too: tab to a node and press Enter.

## Fixes

- **Live and backup routes are now told apart per node** — a node's fallback path is drawn dashed, but it was drawn solid whenever another node happened to use that same hop as its live path. Route roles are now tracked per node, so the same hop can read as live for one node and as a fallback for another.
- **Flags no longer overflow the box on mobile** — the compact layout gained room and operator names are trimmed to what the box holds, at a word boundary.
- **Connector lines are visible on branded themes** — line colour is derived from the text colour instead of the border, which disappeared against a strongly coloured background.

## Improvements

- **Commands are named, not identified** — the result summary says "BGP", "Ping" or "Tracert", the same labels the query form offers, instead of the raw `bgp_route`.
- **The map lost its heading** — the panel already names the query directly above it.
