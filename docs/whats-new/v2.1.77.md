# HopStat v2.1.77

Queries stop showing "Working..." after they finish, and shared links now name the node in the path.

## Fixes

- **Queries hung on "Working..." for up to a minute** — the early-stop watcher was waited on before the command context was cancelled, so every query stayed open until its timeout expired (60s for traceroute, 30s for ping and BGP) even though the command had already returned. Traceroute made this visible: the hops were complete but the terminal kept its running indicator. The final result, history entry and audit record were all delayed by the same amount.
- **Node from a shared link was not selected** — opening a link for a non-default node ran the query on the right node but the node selector snapped back to the default one, because the select echoed an empty value over the selection while its list was still loading.

## Improvements

- **Node in the link path** — a non-default node now reads as `/sofia/ping/8.8.8.8` instead of `/ping/8.8.8.8?node=4`. Names are folded to plain ASCII (`ŞİŞLİ` → `sisli`); nodes whose names collide, or would read as a command, keep their numeric id. Default-node links stay short: `/bgp/1.1.1.0/24`.
- Links shared from v2.1.76 with `?node=<id>` still work and are rewritten to the new form on load.
