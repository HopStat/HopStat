# HopStat v2.2.21

Frontend builds use the latest Node.js security release.

## Improvements

- **Node.js 26.12.1** — Docker image builds, CI, and release builds use Node.js 26.12.1, the latest release from the October 21, 2026 security updates. That release patches c-ares, the eMudhra CA, OpenSSL, undici, and the high-severity DNS, TLS, and Brotli issues.

## Notes

- Building from source now needs Node.js 26.12.1 or newer. The running server is still the Go binary; Node is only used to build the frontend.
