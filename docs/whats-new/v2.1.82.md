# HopStat v2.1.82

The network map is now *the* map on BGP results, and it turns to fit a phone.

## What's New

- **One map instead of two** — the network map replaces the old AS path map at the top of a BGP result. It shows the same path when only one node can answer, and every node's view when more can, so nothing is lost and nothing is shown twice. Reachability through a default route is drawn from the default-route path, same as before.
- **Vertical on mobile** — on a narrow screen the diagram turns to run downwards: nodes across the top, the origin AS at the bottom. That is the shape a phone actually has room for, so the whole map fits with no sideways scrolling.

## Fixes

- **Real flags** — country flags on the map now use the same image source as the rest of the app instead of emoji, which do not render on every platform and were unreadable at label size where they did.
- **Flag no longer sits on the AS name** — a stylesheet rule was overriding the label's alignment, so the flag was drawn over the first characters of the operator name.
