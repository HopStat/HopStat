# HopStat v2.1.89

Hovering a fallback hop no longer lights the live route beside it.

## Fixes

- **A hovered hop lit everything its node holds** — pointing at a hop that carries only a node's fallback highlighted the node's live route too, so the fallback read as part of the current path. A hop now traces only the chain it is actually part of: a fallback hop lights the fallback, a live hop lights the live route. Hovering the node box still shows everything the node holds.
