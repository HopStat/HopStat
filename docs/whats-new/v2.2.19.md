# HopStat v2.2.19

The BGP network map no longer draws a path through a hop it does not use.

## Fixes

- **Hops sitting on another path's line** — when a path skipped a column, the hop placed in that column could land right on the line, so it read as though that path ran through it. The map now keeps every hop clear of the lines that pass its column and moves it to a free row instead.
- **Detours that clipped boxes** — a path that had to go around a box on its own row bowed over it, but still clipped the boxes near either end. It now runs through the gap between rows.
