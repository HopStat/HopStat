# HopStat v2.1.79

The network map now shows backup paths and covers remote agent nodes.

## What's New

- **Backup paths on the map** — a node's selected route is drawn solid, and the alternates it also carries are drawn dashed, so the map shows what traffic would fall back to rather than only where it goes today. Up to four paths per node, with duplicate AS paths collapsed. Reachability that depends on a default route stays dotted, so the two remain distinguishable.
- **Remote agents are included** — nodes running the lg-node agent with BGP lookups enabled now contribute their own view of the target, alongside the nodes peering with the embedded speaker. Agent queries share one bounded budget and a slow or unreachable agent simply drops off the map instead of holding up the query.

## Improvements

- **Copy result** marks each node path as selected (`*`) or backup (`~`).
- Nodes with no route are no longer named under the diagram — they were already left out of it, so the note said nothing the map did not.
