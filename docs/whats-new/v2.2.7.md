# HopStat v2.2.7

Cloudflare Turnstile on the public query form and query API.

## What's New

- **Public queries** — set `turnstile.site_key`, `turnstile.secret`, and `turnstile.hostnames` to show the Turnstile widget on the query form. `POST /api/v1/query` then requires a valid token, so a direct API call cannot skip the check.
- **Node agent** — `/agent/v1` still authenticates with the node bearer key and does not require Turnstile.

## Notes

- Leave the three `turnstile` fields empty to keep the public query API open.
- `turnstile.hostnames` is the public site name Turnstile returns. Do not list `localhost` or `127.0.0.1` on a production server.
