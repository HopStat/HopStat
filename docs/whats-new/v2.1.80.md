# HopStat v2.1.80

Network map labels read straight off the diagram — no hovering required.

## Improvements

- **Country beside the AS name** — each hop now prints its country next to the operator name inside the box (flag when one is available, country code otherwise), instead of hiding it behind a hover popup.
- **No more popups on the map** — the tooltip on AS boxes is gone now that the same information is on the label, and node boxes no longer pop up the queried prefix, which was only repeating what you typed.
- **Only node boxes are interactive** — they remain hoverable and keyboard-reachable to trace a path; AS boxes simply render.
