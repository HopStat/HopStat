# HopStat v2.1.64

Admin update flow now includes a What's New dialog with English release notes from GitHub.

## What's New

- **What's New modal** on the admin dashboard when you click **Update Now** — review English release notes before confirming a self-update.
- **Post-update prompt** — after upgrading, the dashboard shows What's New once for the new version (tracked in browser storage).
- **Manual update path** — when self-update is disabled, a **What's new** link opens the same modal with release notes and a GitHub link.
- Release notes are **English only** for all UI languages; modal chrome (buttons, titles) stays localized.

## Fixes

- Update status API now returns `release_name` and `release_notes` (markdown) from the latest GitHub release for the in-app modal.

## Notes

- Maintain release notes in `docs/whats-new/vX.Y.Z.md` before each tagged release; GitHub Release uses this file as the release body.
