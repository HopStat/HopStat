# HopStat v2.2.14

Dark mode keeps the brand colour for accents on near-black surfaces, and the BGP log now says why a session went down.

## What's New

- **BGP down reason** — when a session drops, the neighbor log shows why: hold timer expired, a NOTIFICATION from either side, or the TCP connection breaking.

## Fixes

- **Dark mode colours** — surfaces, borders and text are now near-black with only a hint of the brand hue, instead of a full wash of it. The brand colour stays on buttons, icons and highlights, and the footer sits darker than the page. Yellow-green brands get slightly cooler dark surfaces so they do not turn muddy.
- **Button text in dark mode** — text on a brand-coloured button uses a dark shade of the brand instead of navy.
- **Passive BGP neighbors** — the log no longer says HopStat is dialling out for a passive neighbor. It says it is waiting for the peer to connect.
- **BGP log duration** — the first state change no longer shows a huge in_state_for value.
- **Self-update and BGP** — before switching to a new version, HopStat closes its BGP sessions with a Cease NOTIFICATION. The router no longer logs a broken pipe.

## Notes

- To match the DGN look, set the main colour in admin settings to `#77bc1f`.
