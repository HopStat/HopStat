# HopStat v2.2.20

Shared query links now preview what the query found, and the query page is redesigned as a measurement sheet.

## What's New

- **Link previews that show the result** — a shared link such as `/traceroute/1.1.1.1` now unfurls in WhatsApp, Telegram, Slack and X with the outcome of the last run: hops, latency and the destination AS for a traceroute, replies and round-trip times for a ping, the prefix, AS path and origin for a BGP lookup. Links without a recent result still preview with the node, command and target.
- **Measurement sheet layout** — the query console sets node, command and target side by side as framed cells, each labelled in its corner. Quick starts are a ruled table and recent queries a grid. Corners are square throughout, admin included.
- **One-click commands** — Ping, Tracert and BGP sit next to each other instead of in a menu, and the arrow keys switch between them.
- **Search engines** — titles, descriptions, canonical links and Open Graph tags are now in the page the server sends, not only added by the browser. `/robots.txt` and `/sitemap.xml` are served, the page language follows the first active language, and query result pages are marked `noindex`.

## Fixes

- **Clicking your IP address on a node without traceroute** — the badge always asked for a traceroute, so on a node with traceroute switched off it failed with "Command not enabled for this node." It now runs the closest command the node allows.
- **Traceroute round-trip times missing** — Linux and BSD traceroute print each time as `0.648 ms`, with the unit as its own word, and those times were dropped. They are now read, so the traceroute table shows them.
- **Unknown paths answered 200** — a mistyped address returned the home page with a success status, so it could be indexed as a copy. It now returns 404 (the page still shows the not-found screen).
- **Site title clipped** — the descender of letters such as "g" in the header title was cut off.
- **Header controls of different heights** — the IP badge, language and theme controls now share one height and spacing.

## Notes

- A new table, `share_snapshots`, is added by an automatic migration. It keeps one short summary per node, command and target for 30 days.
