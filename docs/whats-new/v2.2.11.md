# HopStat v2.2.11

The Turnstile check now shows under the public query box, so a query can get a security token and run.

## Fixes

- **Turnstile widget** — the query form loads Cloudflare's script in a way the widget accepts, so the check appears under the search box instead of an empty gap.
- **Public queries** — submitting a query can obtain a Turnstile token and continue.

## Notes

- Node agent calls still use the node key and are not checked.
- Site key, secret, and hostnames stay in Admin → Settings.
