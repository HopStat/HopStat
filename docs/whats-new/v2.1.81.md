# HopStat v2.1.81

The network map now fits the screen it is on.

## Improvements

- **Fits on mobile** — the diagram scales to the width of the result panel instead of running off the side, and narrow screens switch to tighter geometry so it needs less shrinking to stay readable. A 375px phone shows the whole map with no sideways scrolling.
- **Centred** — when the diagram is narrower than the panel it now sits in the middle rather than hugging the left edge. It is never scaled up past its natural size, so wide layouts look exactly as before.
