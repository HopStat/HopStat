# HopStat v2.2.12

The public footer links to Cloudflare when Turnstile is on, a hidden check no longer leaves a gap under the query box, and the audit log moves past page 10.

## What's New

- **Turnstile privacy** — when the check is on, the public footer links to Cloudflare's Turnstile privacy policy.

## Fixes

- **Hidden Turnstile** — an invisible check no longer leaves an empty band under the query box. The space opens only when the checkbox is shown.
- **Audit log** — pages after 10 are reachable, with previous and next controls.

## Notes

- Node agent calls still use the node key and are not checked.
