# HopStat v2.1.88

Hovering a hop on the network map now lights the route that runs through it.

## Improvements

- **Hops answer the pointer, not just node boxes** — hovering any AS hop highlights the route running through it end to end, so a path can be traced from either direction. A hop shared by several routes keeps the route already in focus, which means following a path hop by hop never jumps the highlight to a sibling's route; elsewhere the first node routing over the hop live wins, with backups only as a last resort.
